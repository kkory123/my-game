게임을 선택해 보세요

1. 계단 올라가기 게임

제목
무한의 계단 (Infinite Stairs)
한 줄 설명
좌우 방향 입력을 통해 장애물을 피해 계단을 빠르게 올라가는 하이페이스 아케이드 게임
플레이어가 하는 일
방향키(좌/우)나 마우스 클릭(좌측/우측 버튼)으로 다음 계단의 방향에 맞춰 올바른 버튼을 연타하며 상층으로 올라간다.
게임이 끝나는 조건
방향 입력을 틀리거나, 일정 시간 동안 입력이 없어 상단의 제한시간 게이지가 바닥날 때

2. 동물이 길 건너가는 게임

제목
크로시 로드 (Crossy Road)
한 줄 설명
달리는 차도를 피해 무사히 건너편 안전지대로 도착해야 하는 건너기 퍼즐 게임
플레이어가 하는 일
방향키(전진/후진/좌/우)를 눌러 차량의 이동 패턴과 속도를 파악한 뒤, 빈 타이밍을 노려 도로를 건넌다.
게임이 끝나는 조건
도로를 지나가는 차에 치이거나, 제한시간이 다 지나도록 안전지대에 도착하지 못할 때

3. 디펜스 / 클릭 타워 포위전

제목
코어 디펜더 (Core Defender)
한 줄 설명
화면 중앙의 코어를 향해 외곽에서 몰려오는 적들을 마우스 클릭과 포탑 배치로 막아내는 방어 게임
플레이어가 하는 일
몰려오는 적을 마우스로 직접 클릭해 공격하거나, 적을 처치해 얻은 자원으로 화면 내 지정 위치에 방어 포탑을 건설·업그레이드한다.
게임이 끝나는 조건
중앙 코어의 체력이 0이 되거나, 정해진 모든 적의 웨이브(Wave)를 전부 막아낼 때
